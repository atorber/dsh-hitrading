## 连板梯队

页面把当日全部涨停股按**当前连续涨停板数**（东财涨停池 `lbc` 字段）分组：

| 分组 | 含义 |
| --- | --- |
| 首板 | 当日首次涨停（`lbc = 1`） |
| 二板 | 连续 2 个交易日涨停（`lbc = 2`） |
| 三板及以上 | 连续 3 / 4 / 5… 板，10 板以上显示「N连板」 |

点击顶部 chips 可只保留某一梯队，再点「全部」恢复。表格默认按**连板数降序 → 首封时间升序**排列，最高板永远在最前。

:::caution[口径]
分组用的是 `lbc`（当前连续板数），**不是** `zttj.ct`（区间累计板数）。例如一只 6 天内 5 板但当前只连了 1 板的股票，归在「首板」，而不是「五板」。
:::

## 指标卡与表格列

顶部 7 个指标卡：涨停家数、首板数、连板数（≥2 板）、最高板、曾炸板数、平均封单、封单合计。

| 列 | 含义 |
| --- | --- |
| 连板 | 首板 / 二板 / 三板… badge，二板以上标红 |
| 现价 / 涨幅 / 成交额 / 换手 | 当日收盘口径 |
| 首封 / 最后封板 | 首次封板与最后一次封板时间 |
| 炸板 | 盘中打开涨停的次数（0 = 未开板，>0 标绿提示） |
| 封单(万) | 封单资金，越大通常封板越坚决 |
| 流通市值 / 行业 | 东财行业板块 |
| `+ 自选` | 一键写入本地自选，按钮持久显示「✓ 已加」/「已在」 |

左侧日期列表显示最近 10 个交易日**每日涨停家数**；切换日期时右侧标题与 badge 会标「已收盘」（最新交易日盘中标「盘中实时」）。

## 数据来源与缓存

- 数据源：东财涨停看板 `push2ex/getTopicZTPool`，与强势股页共用同一份涨停池请求与 10 分钟缓存，不会重复打接口。
- 盘中为实时池，收盘后定稿；仅支持最近 10 个交易日，非交易日不可选。
- 涨停明细、连板梯队、每日家数由 `lib/limitup.js` 一次聚合并由 `limitup` op 返回；`hitrading_limitup` 工具对外提供同样的结构化结果。

:::note
连板梯队是短线情绪观察，封单与炸板只描述当日盘口状态，**不构成投资建议**。
:::
