## 三态数据引擎

集合竞价数据只在 9:15–9:25 有实时意义，页面按时间自动切换三种口径：

| 状态 | 触发条件 | 数据内容 |
| --- | --- | --- |
| 竞价中 | 交易日 9:15–9:25 | 全市场竞价实时数据（虚拟开盘参考价随撮合变动，可撤单），45 秒缓存轮询，状态条显示距 9:25 定格倒计时 |
| 已定格 | 9:25 之后 | 每日 09:25 由内置定时器自动采集的**定格快照**（SQLite 持久化），竞价格 / 竞价量 / 委比收盘后不再变化，可全天复盘 |
| 重建快照 | 历史交易日无快照 | 用全市场开盘价重建竞价涨跌与家数分布；竞价量 / 委比无法回溯，列显示「—」 |

:::tip[为什么需要快照]
9:25 之后行情源的「今开」虽定格为竞价格，但成交量会被全日累计量覆盖，委比（五档委托）也会被盘口变化覆盖。因此插件在每个交易日 **09:25 自动采集一次全市场定格快照**存入 SQLite，此后任何时间都能复盘当日真实的竞价撮合情况。
:::

## 指标卡与指数竞价

顶部 9 个指标卡：高开家数、低开家数、竞价涨停、竞价跌停、大幅高开 ≥3%、大幅低开 ≤-3%、平均竞价涨幅、竞价量（万手）、竞价额（亿）。

四大指数竞价卡片展示上证指数 / 深证成指 / 创业板指 / 科创50 的**竞价开盘价与竞价涨幅**——这是判断当日市场情绪的第一信号。下方「较上一交易日」chips 对比高开家数、竞价涨停数与平均竞价涨幅的变化。

## 涨跌家数分布

11 档半开区间直方图（`<-10%`、`-10~-7` … `7~10`、`≥10%`），红涨绿跌，区间互不重叠。分布形状比单纯的高开家数更能反映竞价情绪：右偏（1~3 档隆起）常见于温和回暖，双峰则说明分歧加大。

## 异动分区与表格

分区 chips：**全部异动**（|竞价涨幅| ≥3% 或 |委比| ≥50%）、**抢筹 ≥3%**、**砸盘 ≤-3%**、**竞价涨停**、**竞价跌停**（涨停阈值按板块自动适配：主板 10%、创业板/科创板 20%、北交所 30%）、**我的自选**、**全市场**。

表格列：代码 / 名称 / 昨收 / 竞价格 / 竞价涨幅 / 竞价量(手) / 竞价额(万) / 委比% / 委差(手) / 行业 / 加自选。竞价涨幅、竞价量、委比等均可点击表头排序；「我的自选」分区可直接把异动自选股与竞价提示对照。

自选股竞价提示按异动幅度排序，标签含义：竞价涨停 / 竞价跌停 / 大幅高开 / 大幅低开 / 高开 / 低开 / 平开。

:::caution[口径与限制]
- 竞价时段价格可撤单，**最终以 09:25 定格为准**；实时态数据仅供观察抢筹 / 砸盘动向。
- 停牌、当日无集合竞价的股票不计入统计（开盘价为 0 时跳过，避免污染分布）。
- ST 股涨跌停为 ±5%，无法从代码识别，涨停 / 跌停分区按所在板块阈值计算。
- 历史交易日的全市场竞价分布无法由免费接口回溯，仅功能上线后每日快照可完整复盘。
:::
