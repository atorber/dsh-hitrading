## 模拟仓

<Shot name="portfolio" alt="模拟仓页" caption="模拟仓：171 万现金账户，买入/卖出按现价成交（可改价），实时市值、当日盈亏与累计盈亏，附成交流水" />

模拟仓带一个**现金账户**：初始资金 171 万，并把手头已有的建仓记录按成本价折算为初始投入。买入/卖出在上方表单输入代码、股数与成交价（留空按实时现价成交），每 15 秒静默刷新现价，实时算：

- 单只市值 = 现价 × 股数
- 单只**累计盈亏** = (现价 − 成本价) × 股数
- 单只**当日盈亏** = (现价 − 昨收) × 股数，即相对上一交易日收盘的当日持仓浮动盈亏
- 买入后成本价按加权平均更新；卖出后扣减持仓，卖完自动移除
- 顶部汇总：**总资产**（现金+持仓市值）、**可用现金**、**当日盈亏**（较昨收）、**总盈亏**（持仓累计）、持仓数

**最新涨跌幅**列是现价 vs 昨收（今日表现），**当日盈亏**列把它换算成金额；**盈亏**列则是自成本价以来的累计盈亏。三者口径不同，可分别按列排序。点「成交流水」展开每笔买卖的时间/方向/价格/股数/金额；「重置模拟仓」会清空持仓与流水、现金回到初始资金。

:::warning
模拟仓是**纯本地记账**，不连接券商、不发送任何交易指令，也没有真实成交撮合。当日盈亏为估算值，不含手续费、税费与分红送转，仅供参考，不构成投资建议。
:::

## 回测

<Shot name="backtest" alt="回测页" caption="回测：策略 + 参数 → 权益曲线 + 收益/回撤/夏普/胜率" />

| 策略 | 逻辑 |
| --- | --- |
| `ma_cross` | 快慢均线交叉（默认 5/20 日），金叉买入、死叉卖出 |
| `macd_cross` | MACD 柱体由负转正买入、由正转负卖出 |
| `rsi_reversal` | RSI 低于超卖阈值买入、高于超买阈值卖出（默认 30/70） |

参数：回看根数（默认 250，约一年）、初始资金（默认 10 万）。输出：期末权益、总收益率、年化、最大回撤、夏普、交易笔数、胜率、最近交易明细与**权益曲线**。

:::caution[回测 ≠ 未来]
内置策略用于验证工具与理解指标，不构成投资建议。历史表现不能预测未来收益。
:::
